Global v3: отдельная разработка на основе global-vpnbot. Не менять исходную Global,
личную версию или работающие серверы. Не публиковать без запроса пользователя.
Установщики и CLI AWG/VLESS сохранять без изменений; новый протокол — отдельный модуль.
Перед изменением выдачи профилей читать bots/vpn-manager_awg/PROFILE_FORMAT_CONTRACT_RU.md.
Основная точка входа — install-global.sh; bots/vpn-manager_awg/install.sh используется
как сохранённая библиотека v2, не как самостоятельный установщик v3.
Подготовка ядра предшествует анкете. Ответы сразу сохраняются, секреты имеют права 0600.
VLESS/Hysteria взаимоисключающие. Выбор протоколов и режима HY2 без значения по умолчанию.
Очередь jobs.sqlite3 хранит намерения; реальное состояние меняют только CLI протоколов.
Не повторять неопределённые изменения сервера автоматически; нужна сверка через CLI.

public_ip=auto выбирает назначенный публичный IPv4; результат сохранять.
channel_mbit=auto измеряет Speedtest; при сбое сообщать и сохранять 100 Мбит/с,
установку продолжать. speedtest-cli — необязательный пакет.
Все изменения служб из бота, включая восстановление при запуске, идут через очередь.
