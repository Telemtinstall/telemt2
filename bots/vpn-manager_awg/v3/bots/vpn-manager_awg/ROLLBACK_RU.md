# Локальная сборка и откат

Сборка: 2026.09.30-ip-egress.1. Установщик: 2.10.0.
Архив содержит прежние локальные исправления аудита, поддержку VLESS Reality
и новую функцию смены IP. Он ещё не опубликован на GitHub.

## Проверка и установка архива

Распакуйте архив в новый каталог, не поверх работающего `/root/vpnbot`.
Из корня распакованного архива:

```bash
bash bots/vpn-manager_awg/install.sh --local-source --dry-run
# Только когда готовы обновлять сервер, от root:
bash bots/vpn-manager_awg/install.sh --local-source
```

`--local-source` не загружает код из GitHub. Для пакетов ОС установщику всё ещё
нужна сеть. После будущей публикации обычный `install_bot.sh` скачает новые
файлы из репозитория и проверит контрольные суммы, включая оба контроллера.
Если старый клон расходится с переписанной историей GitHub, используйте новый
`REPO_DIR`; не делайте принудительный сброс каталога с локальными правками.

## Откат выбранного IP

Каждое изменение создаёт закрытый каталог `/root/vpn-endpoint-backups/<ID>`
с исходными файлами и `manifest.json`. При ошибке применения исходные файлы
восстанавливаются автоматически. Для отмены успешной операции:

```bash
python3 /usr/local/sbin/vpn_ip_switch.py rollback <ID>
```

Замените `<ID>` на имя каталога, например `20260922T120000.123456Z`.
Команда проверяет контрольные суммы всех файлов перед восстановлением,
сохраняет права и владельцев, проверяет и перечитывает nginx при необходимости.
Если после переключения файлы изменились (например, были созданы пользователи),
откат останавливается, чтобы не затереть изменения. Тогда требуется сравнение
с резервной копией вручную. Копии от старого серверного скрипта без поля
`snapshots` также требуют ручного восстановления.

Откат адреса восстанавливает файлы, собственную таблицу nftables и автозапуск
политики. Ключи и AWG-интерфейсы не пересоздаются. Соединения VPN сбрасываются,
а ранее активный Xray перезапускается. Более поздние изменения файлов/правил
защищены от автоматического перезаписывания проверками снимков.
Устройства с уже импортированными профилями нужно перевести на прежний адрес
отдельно. При отсутствии старого адреса на сервере восстановление файлов само
по себе не вернёт доступность VPN.

## Откат обновления программы

Перед обновлением установщик печатает два пути внутри `/root/vpnbot-backups`:
`*-endpoint-components/components.tar.gz` и `*-installer-v2`.
Первая копия содержит прежние контроллеры и VPN-конфигурации; вторая — бота
с согласованными SQLite-копиями. Храните их на сервере, не публикуйте: там секреты.

Для немедленного отката неудачной установки остановите `vpnbot.service`,
`vpnbot-traffic.timer`, `vpnbot-channel.timer` и оба коллектора. Сохраните
текущий каталог бота под новым именем, восстановите каталог `*-installer-v2`
на исходный путь установки и нужные файлы контроллеров из архива компонентов.
Проверьте синтаксис Python/Bash и запустите прежние службы бота и таймеры.
VPN-службы ради отката только программы перезапускать не требуется.
Если изменялись nginx/Xray-конфигурации, проверьте их перед применением.
Не восстанавливайте старые базы и все конфиги поверх новых пользователей:
после эксплуатации новой версии нужен выборочный откат с сохранением свежих данных.
Обновление системных пакетов/ядра этим архивом не отменяется.


## Исправления установщика 2.9.1

Свежая установка по умолчанию создаёт VLESS Reality: `--vless-reality`.
`--vless-direct` сохраняет прежний WebSocket без TLS, `--vless-mask` — HTTPS с доменом.
Параметры Reality: `REALITY_TARGET` (по умолчанию `www.google.com:443`) и
`REALITY_SERVER_NAME` (`www.google.com`). Доступность выбранного target и соединение
из сети клиента проверяются отдельно. Приватный ключ хранится в отдельном файле;
повторный запуск не должен его менять.

Исправлены возврат ошибок apt/скачивания, контрольные точки AWG и создание каталога
logrotate. При продолжении сохраняются режим VPN, пути и `--local-source`.
Существующая установка с неработающим контроллером не переустанавливается молча:
нужно восстановить контроллер. Незавершённая установка может продолжиться по своим
контрольным точкам; неоднозначное состояние останавливается без стирания пользователей.
После окончательного запуска проверяются Xray-конфиг и стабильность службы бота.
Эти проверки не заменяют тестового подключения с другого устройства и проверки после reboot.
