Global v4, Debian 13 (Trixie), только отдельный чистый сервер.
1. Распакуйте полный архив vpnbot-global-v4-2026.11.15.1.tar.gz.
2. cd bots/vpn-manager_awg/v4
3. bash install-global.sh --check
4. sudo bash install-global.sh --onlyprotocol amnezia31
   Либо sudo bash install-global.sh для меню выбора протоколов.
5. Укажите исходящий IPv4 и домен VPN (A-запись настраивается вручную).
6. Если код75 — установщик попросит reboot и напечатает команду продолжения.
7. При успехе sudo bash check-server.sh, затем внешний тест на телефоне.

Не запускайте bots/vpn-manager_awg/install.sh напрямую: это библиотека функций v2.
Не устанавливайте поверх Personal, Global v2/v3 и настроенных чужих VPN.
Секреты/API регистратора в пакет не входят; токен Telegram вводится вами.
Подробности и ограничения — README_RU.md.
