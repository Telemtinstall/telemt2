Global v4: новая установка на чистый Debian 13 / Ubuntu 24+, под root.

apt-get update &&
apt-get install -y --no-install-recommends ca-certificates curl python3 &&
curl -fL --retry 3 https://raw.githubusercontent.com/Telemtinstall/telemt2/main/install-v4.sh -o /root/install-v4.sh &&
chmod 700 /root/install-v4.sh &&
/root/install-v4.sh

Полная инструкция, вопросы и продолжение: README.md.
После ошибки не удаляйте состояние /root/.vpnbot-global-v4.json.
