# VPN-бот Глобал v2

Отдельный пакет в `bots/vpn-manager_awg/v2`. Предыдущая версия в родительской папке не изменяется.
AWG 2.0, AWG 3.1, VLESS Reality; домен необязателен. API регистратора отсутствует.
Введённый домен сохраняется без проверки A-записи. Проверка DNS в меню только справочная;
A-запись меняет сам администратор. Генераторы QR и ссылок сохранены.

## Установка на чистый Debian 13

Войдите как root. Используйте отдельный токен BotFather, который не работает на другом сервере.
Сделайте снимок VPS для полного отката пакетов, ядра и сетевых правил.

```bash
apt-get update && apt-get install -y ca-certificates curl python3
curl -fL https://raw.githubusercontent.com/Telemtinstall/telemt2/global-v2-2026.10.26.1/bots/vpn-manager_awg/v2/install.sh -o /root/install-vpnbot-v2.sh
bash /root/install-vpnbot-v2.sh --check
bash /root/install-vpnbot-v2.sh
```

Загрузчик скачивает фиксированный тег `global-v2-2026.10.26.1`, проверяет SHA256SUMS
и оставляет пакет в `/root/vpnbot-global-v2-global-v2-2026.10.26.1`.
Контрольные суммы проверяют целостность файлов пакета; доверие к источнику обеспечивается HTTPS/GitHub.
Если потребуется перезагрузка из-за ядра/headers, после неё повторите последнюю команду.
Токен вводится скрыто на сервере. TGID администраторов — через запятую.
Откройте UDP 1234, UDP 1235 и TCP 443 в панели провайдера, сохраните доступ SSH.
Не запускайте этот тестовый установщик поверх рабочего личного бота: системные пути общие.

## Проверка после установки

```bash
bash /root/vpnbot-global-v2-global-v2-2026.10.26.1/check-server.sh
```

В Telegram: `/start`, три протокола, создание тестового профиля, импорт QR и подключение
с телефона, проверка Интернета. Для AWG 3.1 отдельно проверьте QR AmneziaVPN · Split Tunneling.
Монитор → Скачать список сайтов выдаёт JSON на 1019 записей; список доступен также
получателю доступа к профилю. Полученный файл нужно импортировать в приложение вручную.

Журнал установки: `/var/log/vpnbot-global-install.log`.
Резервные копии: `/root/vpnbot-backups/`; полный откат свежего VPS — снимком провайдера.
Установка с нуля на Debian 13 пока не подтверждена: её проверяет владелец на отдельном сервере.
Локальные автоматические проверки не заменяют проверку ядра, сети и телефона.
