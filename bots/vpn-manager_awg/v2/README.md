# VPN-бот Глобал v2

Telegram-бот для установки и управления собственным VPN-сервером. Создавайте пользователей, выдавайте конфиги, ссылки и QR-коды, смотрите трафик и управляйте доступом из Telegram.

**Три протокола в одном боте:** AmneziaWG 2.0, AmneziaWG 3.1 и VLESS Reality. Для начала достаточно публичного IPv4 — собственный домен необязателен.

Это глобальная версия без API регистратора. Она находится отдельно в `bots/vpn-manager_awg/v2`; прежняя версия в родительской папке сохраняется.

## Возможности

| Раздел | Что доступно |
| --- | --- |
| VPN-пользователи | Создание и удаление профилей отдельно для каждого протокола |
| Выдача подключения | Конфиги, ссылки и QR в поддерживаемых конкретным протоколом форматах |
| AmneziaWG 3.1 | Отдельный QR **AmneziaVPN · Split Tunneling** для настройки раздельного туннелирования в клиенте |
| Доступ к боту | Администраторы по Telegram ID и выдача пользователю доступа к своему VPN-профилю |
| Мониторинг | Состояние сервера, трафик, CSV, пользователи онлайн, замер скорости и загрузка канала |
| Список сайтов | Скачивание JSON для импорта в Amnezia VPN; в этой сборке 1019 записей |
| Смена IP | Выбор адреса, уже назначенного серверу; переключение подключения и выхода VPN, резервные IP закрываются для VPN |
| Домен | Сохранение имени для профилей и справочная проверка A-записи через `host` |
| Установка | Проверка зависимостей, резервные копии, контрольные суммы пакета и продолжение после перезагрузки |

**Hysteria 2 пока не входит в сборку.** Подробное журналирование посещённых сайтов из личной версии также не включено.

Для Debian 13 и выше. Протестировано на Debian 13.

## Что подготовить

- Чистый сервер **Debian 13 или новее** с systemd, публичным IPv4 и доступом по SSH от `root`.
- Токен Telegram-бота от [BotFather](https://t.me/BotFather) и свой числовой Telegram ID.
- Имя первого VPN-пользователя: 1–32 символа, латинские буквы, цифры, `.`, `_`, `-`.
- Доступ сервера к репозиториям пакетов, GitHub и Telegram API.
- Открытые порты в сетевом экране провайдера:

| Назначение | Порт по умолчанию |
| --- | --- |
| AmneziaWG 2.0 | UDP 1234 |
| AmneziaWG 3.1 | UDP 1235 |
| VLESS Reality | TCP 443 |
| SSH | Ваш порт SSH — не закрывайте его |

Перед установкой сделайте снимок VPS: он позволяет откатить также изменения ядра, пакетов и сетевых правил. Для тестового сервера используйте отдельный токен — два сервера не должны одновременно получать обновления одного Telegram-бота.

## Установка

Последняя опубликованная сборка установщика: **`global-v2-2026.10.27.4`**.

Выполните от `root`:

```bash
apt-get update && apt-get install -y ca-certificates curl python3

curl -fL https://raw.githubusercontent.com/Telemtinstall/telemt2/global-v2-2026.10.27.4/bots/vpn-manager_awg/v2/install.sh -o /root/install-vpnbot-v2.sh &&
bash /root/install-vpnbot-v2.sh
```

Сначала установщик спросит:

1. Telegram ID администратора; несколько ID можно указать через запятую.
2. Имя первого VPN-пользователя.
3. Публичный IPv4 сервера.
4. Токен бота — скрытым вводом.

Затем покажет состав ПО и запросит подтверждение. Во время установки выводятся этапы, зависимости и результат. Позже можно запустить замер скорости или указать скорость канала вручную.

Загрузчик скачивает фиксированную сборку и проверяет её `SHA256SUMS`. Повторный запуск использует тот же пакет, а не произвольное новое содержимое ветки `main`. Контрольные суммы проверяют целостность; источник загрузки — GitHub по HTTPS.

Для проверки загрузки и целостности **без установки системных компонентов**:

```bash
bash /root/install-vpnbot-v2.sh --check
```

### Если потребовалась перезагрузка

Для AmneziaWG нужны совместимые ядро и headers. Если headers для работающего ядра недоступны, установщик может подготовить новое ядро и приостановиться с кодом **75**. Это ожидаемая пауза, но установка ещё не завершена. Автоматически сервер не перезагружается.

```bash
reboot
```

После повторного входа по SSH:

```bash
uname -r
bash /root/install-vpnbot-v2.sh
```

Сравните версию ядра с указанной установщиком. Завершённые этапы и ответы сохраняются. Токен временно хранится отдельно в `/root/.install_vpnbot_global.config.token` с правами 0600, доступен только root и удаляется после успешной установки. После reboot повторите ту же команду: установка продолжится с незавершённого этапа без повторного ввода токена. При переходе со старой сборки токен потребуется один раз, если она его не сохраняла. После успешного завершения повторный запуск той же сборки не переустанавливает бот.

## Первый запуск и меню

Откройте своего бота в Telegram и отправьте `/start`.

```text
Главная
├── VPN
│   ├── AmneziaWG 2.0
│   ├── AmneziaWG 3.1
│   └── VLESS Reality
└── Администрирование
    ├── Настройки
    │   ├── Смена IP
    │   ├── Протоколы
    │   ├── Настройка домена
    │   └── Администраторы
    └── Монитор
        ├── Состояние сервера
        ├── Трафик
        ├── Задания
        └── Скачать список сайтов
```

В разделах кнопки **← Назад** и **🏠 Главная** находятся внизу. При вводе данных доступна **Отмена**. У получателя доступа к профилю своё ограниченное меню: выдача доступа не делает его администратором.

### QR и список сайтов

Кнопки QR для iPhone/Android и QR AmneziaVPN предназначены для разных форматов и приложений. Выбирайте подходящий вариант; успешная генерация картинки сама по себе не подтверждает подключение.

Для AWG 3.1 есть отдельная кнопка **QR AmneziaVPN · Split Tunneling**. После импорта настройте разделение трафика в клиенте.

Список сайтов выдаётся файлом через **Администрирование → Монитор → Скачать список сайтов**, а также доступен получателю расшаренного профиля. JSON нужно импортировать в Amnezia VPN вручную. Замена файла на сервере не обновляет уже импортированные списки на устройствах автоматически.

## Домен и смена IP

Без домена профили используют IP. В **Настройках → Настройка домена** можно сохранить своё DNS-имя. Оно применяется в новых выдаваемых профилях независимо от наличия A-записи.

Проверка через `host` показывает, соответствует ли A-запись выбранному IP. Она только диагностическая: бот **не обращается к API регистратора и не меняет DNS**. Если адрес не совпадает, исправьте запись самостоятельно.

- После смены домена получите и импортируйте новые профили на устройствах.
- После смены IP обновите A-запись вручную. Профилям с прежним неизменным доменом обычно достаточно обновления DNS-кеша и переподключения; поведение зависит от клиента.
- Профили с числовым старым IP нужно получить заново.
- Смена IP прерывает текущие VPN-соединения. Выбирать можно только адреса, назначенные серверу.

## Проверка после установки

```bash
bash /root/vpnbot-global-v2-global-v2-2026.10.27.4/check-server.sh
```

Затем проверьте каждый нужный протокол на телефоне или компьютере: импорт профиля, подключение и доступ в Интернет. Отдельно проверьте Split Tunneling, скачивание списка сайтов и доступ приглашённого пользователя.

Сборка `.4` прошла **161 автоматический тест**, включая генерацию профилей, права доступа, DNS-диагностику, проверку зависимостей и паузу для перезагрузки. Проверки пакета не заменяют полный тест установки и подключения на вашем сервере и устройстве.

## Продолжение, обновление и откат

**Повторный запуск для продолжения незавершённой установки — не универсальная команда обновления любого старого бота.** Переход с другой версии требует проверки конфигураций, контроллеров и резервной копии пользователей.

Не устанавливайте Глобал поверх личной версии с API DNS: они используют общие системные пути. На работающем сервере перед обновлением сохраните базу доступа, VPN-профили, ключи и конфигурации.

| Данные | Путь |
| --- | --- |
| Установленный бот | `/root/vpnbot` |
| Настройки и токен | `/root/vpnbot/.env` |
| Права доступа | `/root/vpnbot/access.sqlite3` |
| Список сайтов | `/root/vpnbot/assets/sites.json` |
| Журнал установки | `/var/log/vpnbot-global-install.log` |
| Резервные копии установщика | `/root/vpnbot-backups/` |
| Копии перед сменой IP/домена | `/root/vpn-endpoint-backups/` |

Полный откат новой установки — восстановление снимка VPS. Резервные копии приложения не отменяют все изменения ОС. При разборе ошибки сообщите этап и последние строки журнала, исключив токены, пароли и VPN-ключи.

## Исправления установщика

- **`.2`** — проверка реального пакета `bind9-dnsutils` на Debian 13 вместо ложного сообщения об отсутствии `dnsutils`.
- **`.3`** — начальные вопросы, описание этапов и отдельный статус ожидания перезагрузки ядра.
- **`.4`** — сохранение ответов и токена до завершения, продолжение после reboot без повторного ввода; защита от повторной установки завершённой сборки.

Технические правила совместимости: [контракт профилей и QR](bots/vpn-manager_awg/PROFILE_FORMAT_CONTRACT_RU.md).
