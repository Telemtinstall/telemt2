# VPN-бот Глобал

Глобальная версия без API регистратора. Сборка GLOBAL-2026.10.26-v2.1.
Инструкция установки из GitHub: README.md. Предыдущая сборка Global проверена
обновлением существующего сервера; установка с нуля проверяется отдельно.
Личная папка domeny-personal и работающий личный бот не изменяются.

## Домен
Настройки → Настройка домена → Сменить домен → выбор назначенного серверу IP → подтверждение.
Домен сохраняется независимо от наличия и значения A-записи; нормализуется регистр/IDN.
Допустимо DNS-имя любого уровня в пределах стандартных ограничений длины.
Адрес применяется в профилях AWG 2.0, AWG 3.1 и VLESS. Ключи и форматы QR сохраняются.
Без заданного домена работает числовой IP. После смены домена нужно заново получить профили.
При смене IP домен остаётся прежним, A-запись администратор меняет самостоятельно.
API, логин и пароль регистратора отсутствуют. Автоматического изменения DNS нет.

Вход в раздел домена и кнопка «Проверить A-запись» выполняют справочную проверку.
При несовпадении с выбранным активным IPv4 бот просит изменить A-запись у регистратора.
DNS-ошибка или отсутствие утилиты не отменяют сохранённый домен.
Если A-записей несколько, все должны совпадать с выбранным IP VPN: резервные IP
могут не принимать VPN-подключения. Проверка использует системный DNS сервера,
поэтому после ручной смены записи возможен старый ответ до истечения TTL.

## Утилита
`python3 /usr/local/sbin/domain_host.py vpn.example.org`
Один аргумент — DNS-имя. Строгая проверка, IDNA, без shell; фиксированный /usr/bin/host,
фиксированные тип A, время ожидания, число повторов. Возвращает JSON с ok/domain/a_records/error.
Сторонние флаги, URL, пробелы, спецсимволы shell и IP вместо домена отклоняются.
Установщик включает пакет Debian bind9-host; DNS не изменяется.
Конфигурация домена: /etc/vpnbot-global/domain.json (создаётся при сохранении).

## Установка и откат
Локальная проверка пакета: `bash install-global.sh --check`.
На отдельном Debian-сервере: `sudo bash install-global.sh`.
Не запускать на действующем личном сервере: это другой вариант приложения,
но системные пути бота и контроллеров общие, одновременная установка не предусмотрена.
Переключения сохраняют резервные копии в /root/vpn-endpoint-backups/.
Откат конкретного переключения: `python3 /usr/local/sbin/vpn_ip_switch.py rollback ИМЯ_КОПИИ`.
Домен включён в тот же манифест, что и сетевые настройки. При несовместимых поздних
изменениях откат останавливается вместо перезаписи файлов.
Исходная личная версия остаётся отдельной точкой возврата для разработки.

Сборщик подробной истории сайтов из личной версии не включён в общий установщик.
Обычные функции бота, монитор, выдача списка сайтов и Split Tunneling QR сохранены.
