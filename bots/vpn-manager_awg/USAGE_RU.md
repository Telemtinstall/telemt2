# VPN Manager v2: установка и использование

## 1. Что понадобится

- сервер с Debian 13+ или Ubuntu 22.04+ и systemd;
- вход под `root` или возможность использовать `sudo`;
- публичный IPv4 либо DNS-имя сервера;
- открытые входящие порты UDP `1234` для AmneziaWG 2.0, UDP `1235` для
  AmneziaWG 3.1 и TCP `443` для VLESS;
- токен Telegram-бота от `@BotFather`;
- числовой Telegram ID каждого администратора.

Если администраторов несколько, их ID вводятся через запятую без пробелов:

```text
123456789,987654321
```

## 2. Установка из GitHub

Войдите на сервер как `root` и вставьте весь блок. Он подходит для Debian и
Ubuntu с пакетным менеджером `apt`, сам устанавливает средство загрузки и не
требует `sudo`:

```bash
apt-get update &&
apt-get install -y --no-install-recommends ca-certificates curl &&
curl -fsSL https://raw.githubusercontent.com/Telemtinstall/telemt2/main/bots/vpn-manager_awg/install_bot.sh -o /tmp/install_bot.sh &&
chmod +x /tmp/install_bot.sh &&
/tmp/install_bot.sh
```

Загрузчик скачает репозиторий в `/root/telemt2`, проверит контрольные суммы и
запустит основной установщик. Сначала он покажет состояние обязательных
пакетов и спросит, можно ли их установить или обновить. Затем он проверит
AmneziaWG 2.0, AmneziaWG 3.1 и VLESS и спросит, можно ли установить отсутствующие варианты либо
обновить их управляющие скрипты.

На чистом сервере общие параметры спрашиваются один раз:

```text
Публичный IP/host для всех VPN [определённый автоматически]:
Имя первого пользователя во всех VPN [vpnuser1]:
```

Далее нужно ввести:

```text
Telegram BOT_TOKEN:
Telegram ID администраторов через запятую:
```

Токен вводится без отображения символов. Установщик проверяет его через
Telegram API и не записывает в журнал установки.

При предложении Speedtest можно нажать Enter. Результат используется для
выбора номинальной скорости канала, необходимой для отображения процента
загрузки сервера.

После успешного завершения отправьте боту `/start`.

### Проверка ОС и ядра

Установщик принимает Debian 13 и новее либо Ubuntu 22.04 и новее. Более старая
ОС отклоняется до изменения VPN-конфигурации с просьбой сначала обновить
дистрибутив.

Для актуального AmneziaWG требуется ядро `6.7` или новее. Если версия ниже,
установщик предлагает установить подходящее ядро вместе с headers:

- Ubuntu 22.04 — `linux-generic-hwe-22.04`;
- Ubuntu 24.04+ — актуальное `linux-generic`;
- Debian 13+ — актуальные `linux-image-amd64` и `linux-headers-amd64`.

После установки ядра нужно выполнить `reboot`, снова войти по SSH и повторить
запуск `install_bot.sh`. Контрольные точки сохраняются: уже выполненные этапы
не повторяются, а установка продолжается с проверки VPN.

## 3. Повторный запуск и обновление

Для обновления используется та же команда. Перед заменой `/root/vpnbot`
создаётся резервная копия в `/root/vpnbot-backups`. Если в `/root/telemt2`
есть несохранённые изменения Git, загрузчик остановится и не перезапишет их.

Если SSH-соединение оборвалось, снова запустите `/tmp/install_bot.sh` либо
повторно скачайте его командой из раздела 2. Завершённые этапы будут
пропущены. Журнал доступен здесь:

```bash
less /var/log/vpnbot-install.log
```

Контрольные точки находятся в `/root/.install_vpnbot.state`. Журнал
ротируется ежедневно и хранится максимум 7 дней.

## 4. Схема меню администратора

Все основные кнопки — reply-кнопки Telegram. Список VPN-пользователей и
карточка выбранного пользователя используют inline-кнопки.

```text
Главное меню
┌──────────────────────┬──────────────────────┐
│ AmneziaWG 2.0        │ AmneziaWG 3.1        │
├──────────────────────┼──────────────────────┤
│ VLESS                │ Админ                │
└─────────────────────────────────────────────┘

AmneziaWG 2.0, AmneziaWG 3.1 или VLESS
┌──────────────────────┬──────────────────────┐
│ Создать пользователя │ Список пользователей │
├──────────────────────┼──────────────────────┤
│ Кто онлайн           │ Главное меню         │
└──────────────────────┴──────────────────────┘

Админ
┌──────────────────────┬──────────────────────┐
│ Состояние сервера    │ Трафик               │
├──────────────────────┼──────────────────────┤
│ Настройки            │ Назад                │
└──────────────────────┴──────────────────────┘

Трафик (при входе отправляются графики и CSV)

├──────────────────────┼──────────────────────┤
│ Кто онлайн           │ Назад                │
└──────────────────────┴──────────────────────┘

┌──────────────────────┬──────────────────────┐
│ Протоколы            │ Администраторы       │
├──────────────────────┴──────────────────────┤

Загрузка канала
┌──────────────────────┬──────────────────────┐
│ 1 час                │ 24 часа              │
├──────────────────────┼──────────────────────┤

│ Назад                                       │
└─────────────────────────────────────────────┘
```

Команды администратора:

- `/start`, `/menu`, `/help` — главное меню;
- `/admin` — администрирование;
- `/create`, `/add`, `/new` — создание пользователя с выбором протокола;
- `/list`, `/clients` — список с выбором протокола;
- `/online` — online сразу по обоим AmneziaWG и VLESS;
- `/traffic` — общий трафик и отчёты;
- `/cancel` — отмена текущего ввода.

В `Настройки → Протоколы` зелёная кнопка означает включённый протокол,
красная — отключённый. После подтверждения бот выполняет `systemctl
disable --now` или `systemctl enable --now`. Отключённый протокол исчезает из
главного меню и перестаёт принимать соединения; пользователи, ключи, базы и
история сохраняются. После включения прежние конфиги снова работают.

В `Настройки → Администраторы` можно добавить администратора по числовому
Telegram ID либо пересланному сообщению, посмотреть список и удалить
добавленного через бот администратора. Записи из `ADMIN_BOT` в `.env`
защищены от удаления. Если Telegram скрыл автора пересылки, ID вводится вручную.

## 5. Создание и управление VPN-пользователем

Выберите протокол и нажмите `Создать пользователя`. Можно ввести имя вручную
либо нажать `Создать автоматически`. При совпадении имени бот сообщит, что
такой пользователь уже существует, и не перезапишет его.

В `Список пользователей` нажмите inline-кнопку нужного пользователя. Для
AmneziaWG доступны:

- QR для iPhone;
- QR для Android;
- QR и копируемый ключ для AmneziaVPN;
- файл `.conf`;
- текст `.conf` для роутера;
- трафик пользователя;
- выдача или отзыв доступа к боту;
- удаление с подтверждением.

Для VLESS доступны QR, копируемая VLESS-ссылка, трафик, управление доступом и
удаление.

При удалении VPN-пользователя удаляются его VPN-настройки, персональная
SQLite-база трафика и выданные права доступа. Системные журналы не изменяются.

## 6. Доступ обычного пользователя

В карточке VPN-пользователя администратор нажимает `Предоставить доступ` и
передаёт полученную одноразовую ссылку владельцу. Владелец открывает ссылку и
нажимает Start. После активации ссылка становится недействительной, а в
карточке администратора появляются Telegram ID, имя, username и время выдачи
доступа.

Один Telegram-пользователь может владеть одновременно профилями AmneziaWG и
VLESS. Он видит только свои профили:

```text
Мои VPN
┌─────────────────────────────────────────────┐
│ AmneziaWG · username                       │
├─────────────────────────────────────────────┤
│ VLESS · username                           │
└─────────────────────────────────────────────┘

Профиль AmneziaWG
  QR для iPhone
  QR для Android
  QR AmneziaVPN
  Получить VPN-ключ
  Прислать .conf
  Текст .conf для роутера
  Мой трафик
  Мои VPN

Профиль VLESS
  Показать QR
  Прислать VLESS-ссылку
  Мой трафик
  Мои VPN
```

Обычному пользователю недоступны создание, удаление, чужие профили, общий
online, общий трафик и администрирование сервера.

## 7. Трафик, графики и состояние сервера

- Суточный трафик каждого VPN-пользователя записывается в отдельную SQLite-базу
  ежедневно в `23:59 UTC`.
- Время хранится как `TIMESTAMP`, счётчики — целыми байтами.
- CSV показывает время UTC и объём в мегабайтах; доступны отчёты по дням и
  месяцам.
- График по дням строится в МБ, график по месяцам — в ГБ.
- Общая загрузка сетевого интерфейса записывается каждую минуту и хранится 90
  дней; после очистки выполняется `VACUUM`.
- `Состояние сервера` показывает CPU, RAM, диск и текущую загрузку канала.
- `Замер скорости` запускает Speedtest вручную и временно нагружает канал.
- `Кто онлайн` в админке показывает оба протокола сразу.

## 8. Проверка служб

```bash
systemctl status vpnbot.service --no-pager
systemctl status vpnbot-traffic.timer --no-pager
systemctl status vpnbot-channel.timer --no-pager
/usr/local/sbin/awgctl -j list
/usr/local/sbin/vlessctl -j list
```

Последние сообщения бота:

```bash
journalctl -u vpnbot.service -n 100 --no-pager
```

Перезапуск бота:

```bash
systemctl restart vpnbot.service
```
